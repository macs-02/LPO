Completare le classi Find e Height, assicurando che tutte le asserzioni nelle classi di test abbiano successo.

1. Classe Find (File System)
   Completare il costruttore per inizializzare il campo name.
   Implementare i metodi visitFile e visitFolder per verificare l'esistenza nel file sistem di un file con il nome cercato.
2. Classe Height (Alberi Binari)
   Implementare i metodi visitEmpty e visitNonEmpty per calcolare l'altezza dell'albero binario.
   Nota: Per l'esecuzione, ricordare di abilitare le asserzioni con l'opzione -ea.
